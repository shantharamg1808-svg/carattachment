📝 MANAGING THE PROJECT
═══════════════════════════════════════════════════════════════════════════════

ADD A VEHICLE
├── Open: src/data/vehicleData.js
├── Add new object to array
└── Done! (Auto-appears in app)

ADD A CATEGORY
├── Open: src/utils/formatters.js
├── Update CATEGORIES array
└── Update vehicle data

ADD A FILTER
├── Open: src/utils/formatters.js
├── Add new filter options
├── Update filtering logic
└── Add to FiltersSection.jsx

CHANGE STYLING
├── Option 1: Edit src/App.css (global)
├── Option 2: Update Tailwind classes in components
└── Save → Auto-reload (npm run dev)
