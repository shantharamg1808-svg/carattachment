## 📂 Directory Details

### Root Level
- **Configuration Files**: Vite, Tailwind, PostCSS, Git settings
- **index.html**: Entry point for the application
- **package.json**: Lists all dependencies and scripts

### `/src/` - Source Code (Main Development Area)

#### Core Files
```
src/
├── App.jsx              # Central state management & filtering logic
├── App.css              # Global styles, Tailwind directives, animations  
└── main.jsx            # React entry point (mounts App to #root)
```

#### `/src/components/` - Reusable Components
Each component is responsible for a specific UI section:

| Component | Responsibility |
|-----------|-----------------|
| `Header.jsx` | Top hero section + search functionality |
| `CategorySummary.jsx` | Category filter buttons with avg stats |
| `FiltersSection.jsx` | Budget/Transmission/Fuel dropdowns + vehicle count |
| `CarCard.jsx` | Individual vehicle card (name, price, profit) |
| `CarGrid.jsx` | Grid container + empty state message |
| `DetailModal.jsx` | Full vehicle details popup |

#### `/src/data/` - Data Management
```
src/data/
└── vehicleData.js       # Array of 24 vehicles with complete details
                         # Each vehicle: id, name, specs, financials, breakdown
```

**When to edit**: 
- Add/update vehicles
- Modify vehicle financial data
- Change vehicle specifications

#### `/src/utils/` - Utilities & Helpers
```
src/utils/
└── formatters.js        # Reusable functions and constants
```

**Contains**:
- `formatCurrency()` - Format numbers as INR
- `CATEGORIES` - Array of vehicle categories
- `BUDGET_RANGES` - Budget filter options
- `checkBudgetRange()` - Budget filter logic

### `/dist/` - Build Output
Generated by `npm run build`. Contains minified & optimized files for production.

### `/node_modules/` - Dependencies
Generated by `npm install`. Contains all packages (128 packages total).

## 📝 Key Differences Between Components

### Stateless Components (Props-based)
- `Header.jsx` - Receives props, calls parent callbacks
- `CarCard.jsx` - Displays car data, triggers modal
- `DetailModal.jsx` - Shows details for selected car

### Stateful Components (State management)
- `App.jsx` - Manages all app state, filters, and selection
- `CategorySummary.jsx` - Uses useMemo for stats calculation

## 🔍 How Files Interact

### Adding a New Vehicle
1. Edit `vehicleData.js` → Add vehicle object
2. `App.jsx` automatically filters it (useMemo)
3. `CategorySummary.jsx` recalculates stats
4. `CarGrid.jsx` displays new card
5. `DetailModal.jsx` shows details when clicked

### Changing Filter Logic
1. Edit `formatters.js` → Update filter function
2. `App.jsx` uses it in useMemo
3. `CarGrid.jsx` receives updated filteredData
4. UI automatically updates

### Styling Changes
1. Edit `App.css` → Global changes
2. Or modify Tailwind classes in component files
3. Vite auto-reloads (npm run dev)
